Why does B-Tree indexing operate in O(log N) time compared to unindexed O(N) table scans?
B-Tree maintains a balanced multi-way node hierarchy. For 1,000,000 records, a B-Tree search requires at most 3 to 4 disk block reads, whereas an unindexed scan requires sequential disk block traversal.
What is the condition for Third Normal Form (3NF)?
A relation is in 3NF if it is in 2NF and has no transitive functional dependencies (i.e. every non-prime attribute is non-transitively dependent on candidate keys).
How does ACID atomicity protect university lab submissions during upload?
Atomicity ensures the database record and object storage ingestion succeed together as a single unit. If the network drops midway, the transaction rolls back, preventing catalog corruption.
